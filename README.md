# Sahil Singh — Developer Portfolio

Personal portfolio of Sahil Singh, a computer science student at KIIT focused on AI/ML, developer tools, distributed systems, and full-stack engineering.

**Live site:** https://sahilsingh.is-a.dev

## Featured work

- **OfflineUPIMesh** — C++ peer-to-peer payment engine exploring offline transactions, duplicate-packet protection, encryption, and deferred settlement.
- **SantaClaw** — autonomous agentic coding framework with repository analysis, planning, isolated execution, and human-approved changes.
- **NoJudgement** — real-time speaking-practice platform built around WebRTC, speech recognition, and AI feedback.
- **Agent Zero** — multi-agent productivity system connecting natural-language intent to workflow execution.

## Built with

Next.js, React, TypeScript, Tailwind CSS, Motion, and modern web tooling.

pnpm install
